# User Management System

## Overview

This project is a user management system with a RESTful API built in PHP and a frontend interface built with HTML, Bootstrap, and JavaScript.

## Features

- **Backend**: RESTful API for CRUD operations on user entities.
- **Frontend**: User-friendly interface with real-time password strength validation.
- **Database**: SQL database schema for storing user data.
- **Version Control**: Git and GitHub for version control and collaboration.
